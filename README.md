# ColorFlow for After Effects

A powerful extension for Adobe After Effects that helps you analyze and manage colors across multiple shape layers, including gradients.

**Created by Adrian Wulfrath**

## 🎨 Features

- **Color Analysis** - Instantly detect all fills, strokes, and gradients in selected shape layers
- **Batch Color Changes** - Update all instances of a color across multiple layers at once
- **Color Statistics** - See how many times each color appears in your project
- **Custom Color Libraries** - Save and organize your favorite colors into custom palettes
- **Export & Import Libraries** - Share color palettes with your team or across projects
- **Smart Color Copying** - Copy and paste colors between different elements
- **Gradient Support** - Full support for gradient fills and gradient strokes

## 📦 Installation

1. **Download** the `colorflow.zxp` file from this repository

2. **Install using ZXP Installer:**
   - Download ZXP Installer from: https://aescripts.com/learn/zxp-installer/
   - Open ZXP Installer
   - Drag and drop `colorflow.zxp` into the window
   - The extension will install automatically

3. **Restart After Effects**

4. **Open ColorFlow:**
   - Go to `Window > Extensions > ColorFlow`

## 🚀 How to Use

1. **Select** one or more shape layers in your composition
2. **Click** "Analyze Shapes" to see all colors used
3. **Click** any color to change all instances of that color at once
4. **Save** frequently used colors to your custom libraries
5. **Export** your color palettes to share with your team

## ⚙️ Requirements

- Adobe After Effects CC 2017 or later
- Windows or macOS
